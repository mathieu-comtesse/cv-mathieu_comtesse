# Inventaire de conservation de Ma pièce

La référence est `90f6b5d5655ce46eb563e90f466f04bcebdb1765`. Le [JSON avant/après](room-scene-inventory.json) décrit le graphe Three.js complet après le chargement des objets différés et du pont Native. Il conserve les chemins des nœuds, les identifiants et leurs parents interactifs, la visibilité, les transformations locales, les matériaux et les stations. L’orientation est un quaternion `[x, y, z, w]`. Les positions et les échelles suivent les axes de Three.js, avec Y vertical. Les valeurs de la capture d’inventaire correspondent au repos initial.

Les sources chargées par le navigateur figurent dans le JSON. Les constructeurs imbriqués, les maillages anonymes, les particules et les nœuds du rig sont repérés par le chemin complet. Les contours d’encre masqués pour la direction artistique restent identifiables dans le graphe. Une géométrie visible peut être conditionnée par l’activité, par exemple les pochettes ou le jardin derrière les shoji.

`tools/test-room-art.mjs` collecte le graphe. En mode comparatif, il exige les mêmes identifiants, stations, clés de navigation et nœuds initiaux. Il compare aussi les transformations des éléments interactifs fixes. La matrice d’essais est dans le [rapport de régression](room-regression-report.md).
