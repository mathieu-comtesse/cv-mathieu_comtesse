## Jouer à Talas

**[Lancer Talas — Les sept ateliers](https://mathieu-comtesse.github.io/cv-mathieu_comtesse/talas-refonte/)**

Le jeu s’ouvre directement dans le navigateur. Aucune installation ni serveur local à lancer. Attendre la fin du chargement initial, puis cliquer sur Continuer.

Q/D ou flèches : marcher ; Maj : courir ; E : ouvrir l’atelier ; M : carnet. Les commandes de chaque activité sont affichées avant de commencer.

La refonte contient sept chapitres, quinze activités, des personnages animés et les dialogues Talas. Son rendu reste en cours d’amélioration.

[Consulter les sources Unity et les contrôles de la refonte](https://github.com/mathieu-comtesse/cv-mathieu_comtesse/tree/feat/talas-unity-refonte/talas-unity)
