UNGA BUNGA
45001

Incarne Dylan. Explore le village, consulte ses habitants et transforme les ateliers pour prévenir les accidents.

Préparation du chargement…

Une aventure conçue pour 45 minutes, avec sauvegarde dans ce navigateur.
Sur téléphone : mode paysage. Graphismes et commandes se règlent pendant la partie.

Humour noir et accidents fictifs. Effets d’accidents réglables dans le jeu.

Découvrir le projet

Commandes

Tactile : joystick à gauche, caméra à droite. Approche un habitant puis touche « Parler ». Sac, fabrication et journal restent accessibles en haut de l’écran. Touche la minicarte pour l’agrandir.

Clavier : W A S D pour marcher, Maj pour courir, Espace pour sauter, C pour s’accroupir, E pour interagir, Tab pour le sac, V pour fabriquer, M pour la carte, J pour les missions, T pour l’arbre ISO. Les touches sont modifiables dans les réglages.

Les dialogues du village arrêtent le compte à rebours. Le duel du menhir possède ses propres commandes affichées à l’écran : J/K pour les coups, L pour la garde et E pour décider.

Paramètres de démarrage

Les sous-titres, les aides, les touches et les effets d’accidents se règlent dans le jeu.
